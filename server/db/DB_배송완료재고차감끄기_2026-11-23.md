# 배송 완료 재고 차감 끄기 (⑪-③, 2026-11-23)

「DB_주문관리_변경사항_2026-11-17」의 **1장 5번, 5장 `delivered` 줄, 9장 재고 탭 항목을 대신합니다.**

## 바뀐 것

| 항목 | 전 | 지금 |
|---|---|---|
| `order/status` `delivered` 수신 | 상품별 수량만큼 `stock`에서 빼고 `stock_log`에 `delivered` 기록 | 상태·송장·성적서만 저장. **`stock`, `stock_log`는 안 건드림** |
| 스위치 | 없음 | `mqtt_db_writer.py` 위쪽 `DEDUCT_STOCK_ON_DELIVERY = False`. `True`로 바꾸면 예전 차감이 돌아옴 |
| `order/stock` 구독·저장 | 그대로 (F3이 더 안 보내므로 실제로는 안 들어옴) | |
| 음수 재고 | 서버 PC에 aa6 = -4 | `DB_변경_2026-11-23_재고음수정리.sql`로 0으로 맞춤. `stock_log`에 `adjust`, `changed_by='db:11-3 reset negative'`로 기록 |

저장소 버전(조시현 `server/rules` 추가본) 기준이며, 바뀐 줄은 스위치 3줄과 조건 1줄뿐입니다.

## 적용 순서 (서버 PC)

1. `server/db/mqtt_db_writer.py` 교체 후 저장 프로그램 다시 실행
2. 그다음 `DB_변경_2026-11-23_재고음수정리.sql` 실행 (순서가 바뀌면 옛 프로그램이 다시 음수를 만들 수 있음)
3. 마지막 확인 쿼리 `SELECT … WHERE stock_packs < 0` 결과 0줄

## 검증

SQLite 시험 48개 통과: 배송 완료 시 재고·기록이 그대로인지, 스위치를 켜면 예전처럼 한 번만 빠지는지, 최종 상태 변경 거부.
