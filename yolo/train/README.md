# 학습 설정 (train)

| 파일 | 모델 | 클래스 |
|---|---|---|
| `top.yaml` | 위 카메라 → `models\top_best.pt` | `minus_up`, `plus_up` |
| `side.yaml` | 앞·뒤 카메라 → `models\side_best.pt` | `object`, `scratch`, `damage`, `corrosion` (팀 라벨링 `classes.txt` 순서, 11/19 확정) |

- 클래스 이름은 통신 규약 3-2의 `polarity`·`defects[].type` 값과 같다 → `yolo_vision.py`가 변환 없이 그대로 보낸다.
- **라벨링을 시작한 뒤에는 클래스 순서·이름을 바꾸지 않는다** (바꾸면 라벨 파일 번호가 전부 어긋남).
- `yolo_vision.py`는 모델을 열 때 약속에 없는 클래스가 있으면 경고를 띄운다. 대문자·띄어쓰기·`-`는 자동으로 맞춘다 (`Plus-Up` → `plus_up`).

## 폴더 모양 (학습 PC)
```
yolo_data\top\images\train\*.jpg   labels\train\*.txt
              images\val\*.jpg     labels\val\*.txt
yolo_data\side\ (같은 모양)
```
- 사진의 약 80%는 train, 20%는 val. 같은 순간에 찍은 비슷한 사진이 train·val에 나뉘지 않게 찍은 묶음 단위로 나눈다.
- 빈 퍽·아무것도 없는 사진도 섞는다 (라벨 파일은 비우거나 만들지 않음).

## 불량 샘플 만들기 (안전)
- **알카라인 AA만.** 겉모양만 바꾼다. 찌르기·가열·분해·눌러 찌그러뜨리기 금지.
- `scratch`: 겉 비닐에 펜·마커로 긁힌 자국처럼 표시하거나 아주 가볍게 긁는다. **비닐을 뚫어 금속이 드러나게 하지 않는다** (합선 위험).
- `damage`: 테이프·마커로 찢김·변형처럼 보이게 꾸민다. 실제로 찌그러뜨리거나 비닐을 벗기지 않는다.
- `corrosion`: 물감·분필 가루 등 **마른 재료**로 표시한다. 소금물·식초 같은 액체로 실제 부식을 만들지 않는다.
  실제로 누액(흰 가루·끈적임)이 있는 건전지는 장갑을 끼고 다루고, 측정 헤드에 올리지 않는다 (누액은 알칼리성).
- 라인에서 외관 불량은 측정을 건너뛰므로 불량 샘플은 포고핀에 닿지 않는다.
